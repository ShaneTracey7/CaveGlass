This is a web app that displays live sports data in a user-friendly way. Ideally, it's to be run on a secondary monitor while you are watching the game. Perfect for man-caves. It is currently only using NHL data, as that's the only free major sports API I could find. 


Front end: React.js (hosted on GitHub Pages)

Back end: Express.js (hosted on Render)
